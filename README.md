# Subybara

Subybara is an Android subscription tracker developed for our Mobile Development course. It helps users keep track of their subscriptions, monthly expenses, and upcoming billing dates in one place.

Users can manually add and manage their subscriptions, including updating their details and tracking whether they are active, paused, or canceled.

Subybara is only a tracking app. It does not process payments or directly cancel subscriptions with service providers.

## Technologies Used

- **Kotlin** – Main programming language
- **Jetpack Compose** – Building the app's UI
- **Material 3** – UI components and styling
- **Compose State** – Managing temporary subscription data
- **Navigation Compose** – Navigation between screens
- **Gradle** – Project build and dependency management
- **JUnit 4** – Unit testing
- **Compose UI Testing** – Testing screen interactions and user flows
